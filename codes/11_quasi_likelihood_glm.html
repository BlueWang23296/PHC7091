The same quasi-likelihood model can be fit with glm. The model uses $g(\mu)=\log(\mu/(1-\mu))$ and variance $V(\mu)=\mu(1-\mu)$.

glm1 <- glm(y ~ Site + Variety,
            family = quasi(link = "logit",
                           variance = "mu(1-mu)"))

summary(glm1)
